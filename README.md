# AI Life OS · AI 化个人生活操作系统

> 把日常生活数据（饮食、训练、睡眠、阅读）交给 AI 长期托管：你负责随手说，AI 负责记录、估算、出报告。

这是一个正在运行的真人项目：作者是南京财经大学大数据应用与管理专业本科生，从 2026 年 10 月起用自己的真实生活做第一个测试用户。

## 它解决什么问题

- 健身/饮食打卡坚持不下来 → 打卡降为"发一条微信消息"，整理、估算、趋势分析全部由 AI 完成
- 文档散落各种格式 → Markdown 是唯一数据源，Word/PPT 是自动生成的"排版视图"
- AI 对话没有记忆 → 用本地档案文件 + 记忆索引实现跨会话长期记忆

## 快速开始

```bash
# 把任意 Markdown 目录生成同名 Word 文档(楷体 15pt)
cd tools && npm install docx
node md2docx.js <你的markdown目录>
```

## 设计决策(为什么这么做)

| 决策 | 理由 |
|---|---|
| Markdown 作为唯一数据源 | 纯文本、可版本管理、AI 读写零损耗 |
| Word/PPT 是生成品不是源文件 | 排版视图随做随扔,源数据永不破坏 |
| 模板 + AI 解析而非表单 | 用户只需说人话,结构化交给 AI |
| 本地档案文件当 AI 记忆 | 跨会话可迁移、用户可审计、隐私可控 |
